# 本地数据与测试输出

除本说明外，本目录内容均被 Git 忽略，公共仓库不包含私人录音、视频、音色样本或测试结果。

| 目录 | 用途 |
|---|---|
| `runtime/logs/` | 正式版运行日志 |
| `runtime/test_audio/` | 正式版测试实验室的云端译音、虚拟麦克风回录及校准测试音频 |
| `runtime/` 其他文件 | 会话运行文件和临时配置 |
| `virtual-mic/` | 独立虚拟麦克风测试工具输出 |
| `voice-clone/recordings/` | 使用者自己准备的声音复刻 / 文件测试样本 |
| `voice-clone/outputs/` | 文件译音 WAV 与 JSON 摘要 |

## 保存与清理

- 普通实时会话、测试实验室和文件译音测试的保存行为不同；不能把“普通会话不录音”理解为整个项目不会产生任何音频文件。
- 测试实验室输出可在 Web 测试页面试听、逐个删除或删除全部。先停止测试，再删除对应录音。
- CLI 文件译音的 JSON 摘要可能包含原文、译文、音色 ID 和调用信息，应按私人数据处理，不要直接公开。
- 手工清理前先停止对应服务，确认文件不是仍在写入的录音。清理测试输出不会删除阿里云的音色；云端音色需通过管理页面 / CLI 单独删除。
- 自己的原始声音样本应按需另行备份。Git 不保存这些文件，也不能用 Git 恢复已删除的样本。

详细操作见[测试实验室使用](../docs/测试实验室使用.md)和[声音复刻使用说明](../docs/声音复刻使用说明.md)。
