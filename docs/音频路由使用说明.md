# 音频路由使用说明

先启动根目录 `start.bat`，进入“音频设备”页面检查设备。

## 三种运行模式

- 远端字幕：采集电脑播放的会议或视频声音，生成本地翻译字幕。
- 麦克风字幕：采集自己的讲话，显示识别原文或翻译；可选择同时输出克隆声音。
- 会议同传：远端声音生成字幕，自己的讲话翻译并用克隆声音输出。

字幕来源可独立选择仅对方、仅自己或双方。原文、译文、标签、字体和背景样式在“字幕”页面设置。

## 腾讯会议、Teams 等会议软件

1. 本应用麦克风选择实际说话的物理麦克风。
2. 远端媒体捕获选择会议播放声音的物理耳机端点。
3. 虚拟输出选择 `CABLE Input`。
4. 会议软件麦克风选择 `CABLE Output`，扬声器保持物理耳机。
5. 先执行测试实验室的本地路由测试，再测试实时克隆译音。

VB-CABLE 的方向是 `CABLE Input` 播放端 → `CABLE Output` 录音端。避免把物理麦克风和克隆译音同时混到会议输入，也避免把会议扬声器设置为 VB-CABLE。

## 麦克风与延迟

普通使用先选择“平衡模式”。靠近耳麦讲话，先校准输入电平。按住说话保护和自定义快捷键可在总览页设置，快捷键需要总览网页具有焦点。

讲话结束后可松开按键，等待剩余翻译和克隆声音播放。整场结束使用页面“停止程序”或根目录 `stop.bat`。

总览中的延迟来自实际链路事件；尚未采样时显示“—”。测试实验室可分别试听云端译音和从 CABLE Output 回录的声音。

## OBS 录屏

需要字幕时捕获悬浮窗或控制台字幕区域。需要克隆译音时把录音输入设为 CABLE Output。检查物理麦克风轨和桌面音频轨，避免录入重复原声或形成反馈。
