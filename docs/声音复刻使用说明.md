# 声音复刻使用说明：音色管理、CLI 与克隆译音验证

本项目使用阿里云百炼 `qwen-voice-enrollment` 管理音色，再由 `qwen3.5-livetranslate-flash-realtime` 使用该音色生成翻译后的语音。它不是本地声音训练，也不是普通文本朗读 TTS 的封装。

音色创建的 `target_model` 必须与后续使用模型一致；不要把 Omni、其他 Qwen-TTS 或 CosyVoice 音色 ID 当成已经可用的 LiveTranslate 音色。[声音复刻 HTTP API](https://help.aliyun.com/en/model-studio/voice-clone-design-http-api)

## 1. 云端与样本准备

需要 API Key、Workspace ID、对应区域、模型权限和可用额度。只使用本人或已取得明确授权的声音；真实创建和翻译可能产生费用。

样本建议：

| 项目 | 建议 / 当前处理 |
|---|---|
| 内容 | 单人、自然语速、连续清晰，无音乐、其他人声或明显环境噪声 |
| 时长 | 推荐 10–20 秒；独立 CLI 对 WAV 校验至少 3 秒且不超过 60 秒 |
| 格式 | WAV、MP3 或 M4A；视频不是直接可上传的音色样本，需先提取音频 |
| WAV | 单声道、16-bit PCM、采样率至少 24 kHz；不要把实时传输用的 16 kHz 格式直接当复刻样本规范 |
| 上传大小 | 本项目本地样本要求 Data URL 编码后小于 10,000,000 字节，Base64 会放大文件；界面只做格式 / 大小等检查，云端还会校验质量 |
| MP3 / M4A | CLI 提示采样率、声道和时长由服务端校验 |

要求和录制建议以[官方声音样本指南](https://help.aliyun.com/en/model-studio/voice-cloning-user-guide)中对应模型章节为准。音色样本和实时语音输入的格式用途不同。

可用以下文字自然朗读，实际时长按个人语速调整，不必刻意模仿他人：

> 大家好，这是我的声音复刻样本。我会用自然、清晰而稳定的语速，介绍今天的会议安排。我们先讨论项目进展，再确认下一步的时间和任务。希望中英文交流都准确、顺畅，也保持我的声音特点。

填写样本文字时应与真实录音一致；不要把示例文本原样填写到内容不同的录音上。

## 2. Web 音色管理

1. 根目录运行 `start.bat`，在“接口与翻译”保存百炼配置。
2. 打开“音色管理”，选择 WAV / MP3 / M4A 样本。
3. 设置音色短名称，使用 1–16 位字母、数字或下划线；选择实际样本语言，按需填写录音文字。
4. 点击“上传并创建音色”，等待成功，再刷新列表确认 ID 与目标模型。
5. 在列表选择音色，回到总览 / 测试实验室确认已选 ID。
6. 做中文 → 英文、英文 → 中文的实时译音试听，检查音色、目标语言和尾句。
7. 删除前确认该音色不再使用；删除是云端不可逆操作，不是删除本机录音。

正式版上传样本在本次请求中处理，不额外把上传样本作为文件保存；云端仍会收到样本并创建音色。测试产生的译音 / 回录是另一类本地保存数据。

### 复刻频率不是音色开关

| 策略 | 官方 voice 参数要求 | 说明 |
|---|---|---|
| `never` | 预先创建的克隆 `voice_id` | 不在实时响应中重新复刻，使用固定音色；本项目推荐 |
| `once` | `default` | 会话中按输入声音做一次实时复刻 |
| `always` | `default` | 按响应动态复刻，适用于需要适应说话人变化的场景 |

页面选择频率不会自动把已有固定 ID 转换成 `default`。使用 `once/always` 时，在“接口与翻译”的音色 ID 字段按官方要求填写，并做真实会话验证；不要只修改频率然后沿用固定 ID。复刻完成前也不应假定立刻就是指定说话人的音色。[LiveTranslate 音色策略](https://help.aliyun.com/en/model-studio/qwen3-5-livetranslate-flash-realtime)

## 3. 独立 CLI 的全量配置

运行 `install.bat` 后，独立配置位于 `config/voice-clone/voice_clone.local.yaml`，由公开模板首次复制。正式版 Web 与 CLI 配置独立，需另行填写：

| 分组 | 应配置的内容 |
|---|---|
| `aliyun` | API Key、Workspace ID、区域、HTTP 超时；环境变量 `DASHSCOPE_API_KEY` 优先 |
| `service` | enrollment 模型、target 模型、音色短名称；当前固定 LiveTranslate 目标模型 |
| `audio` | 本地样本或公网 HTTPS URL（二选一）、MIME、样本文字、语言和大小 / WAV 校验 |
| `listing` | 默认页码、每页条数 |
| `output` | 表格 / JSON 输出以及请求 ID 显示 |
| `recording` | `prompt` 显示的录音文案 |
| `translation_test` | 已创建的 voice_id、测试输入 / 输出路径、源 / 目标语言、分块、实时节奏和超时 |

模板中的 `YOUR_WORKSPACE_ID` / `YOUR_VOICE_ID` 等是占位符。配置文件内相对路径以该配置所在目录解析；模板的 `../../data/...` 指向项目根目录的 `data/`。CLI 的 `--audio` 显式路径则按当前工作目录解析。

默认样本路径为 `data/voice-clone/recordings/voice_sample.wav`。公共仓库没有这个私人文件，需要放入自己的录音或修改本地配置。

## 4. CLI 命令

以下命令从项目根目录执行，PowerShell 和 CMD 都可使用：

```bat
REM 显示录音文案
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts\manage.ps1 -Action voice prompt

REM 本地配置 / 样本检查，不发送音色创建或翻译请求
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts\manage.ps1 -Action voice check

REM 分页查询
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts\manage.ps1 -Action voice list --page-index 0 --page-size 10

REM 创建：使用独立配置中的样本
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts\manage.ps1 -Action voice create

REM 创建：显式指定自己准备的本地样本
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts\manage.ps1 -Action voice create --audio data\voice-clone\recordings\voice_sample.wav --name my_voice --language zh

REM JSON 查询
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts\manage.ps1 -Action voice list --json

REM 删除：必须替换为真实 ID，执行时会再次确认
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts\manage.ps1 -Action voice delete YOUR_VOICE_ID
```

PowerShell 可以执行这些 `powershell.exe` 命令，但 `REM` 注释只用于 CMD，PowerShell 注释应改为 `#`。创建和删除有交互确认；`--yes` 用于明确接受费用或不可逆删除的非交互场景，不建议随意省略确认。

可使用 `--audio-url` 传入无需鉴权且公网可访问的 HTTPS 音频地址；不要使用内网地址、临时私人地址或带账号凭据的 URL。详情按 `-Action voice --help` 查看。

创建输出的完整 Voice 值就是后续 `voice_id`。CLI 创建不会自动替你在正式版 GUI 中选择该音色，也不会自动替换 `translation_test.voice_id`。

## 5. 文件音频 → 克隆翻译音频验证

这个功能属于 `bailian_voice_clone.translate_test` 模块，不是音色管理 CLI 的 create/list/delete 子命令，也不是实时会议设备推流。

先在独立配置的 `translation_test` 中设置：

- `voice_id`：有效、针对本项目模型创建的音色。
- `input_file`：自己的测试音频；使用模板时默认与声音样本相同。
- `output_file`：私人的 WAV 输出路径。
- `source_language: zh`、`target_language: en`：中文转英文；反向测试相应交换。
- `realtime_pacing`、分块和结束超时：控制发送节奏与收尾，不等于实际会议端到端延迟。

PowerShell：

```powershell
$taskVoiceSource = Join-Path (Get-Location) 'backend\voice_clone\src'
$env:PYTHONPATH = "$taskVoiceSource;$env:PYTHONPATH"
$env:PYTHONUTF8 = '1'
.\.venv\Scripts\python.exe -m bailian_voice_clone.translate_test --config .\config\voice-clone\voice_clone.local.yaml
```

CMD：

```bat
set "PYTHONPATH=%CD%\backend\voice_clone\src;%PYTHONPATH%"
set "PYTHONUTF8=1"
.venv\Scripts\python.exe -m bailian_voice_clone.translate_test --config config\voice-clone\voice_clone.local.yaml
```

该模块确认真实调用后，解码输入、发送 16 kHz PCM，接收克隆译音，发送 `session.finish` 并等待 `session.finished` 收尾；成功后保存 24 kHz WAV 和同名 JSON 摘要。默认输出位于 `data/voice-clone/outputs/`。FFmpeg 支持情况和输入文件实际可解码性需本机验证。

JSON 摘要可能含原文、译文、voice_id 和调用信息，不要直接公开。删除测试文件不会删除云端音色。

## 6. 常见问题

| 问题 | 检查方向 |
|---|---|
| 配置好了 Web，CLI 仍认证失败 | 两套配置独立；核对 CLI 配置或环境变量 |
| 创建提示 24 kHz / 单声道错误 | 检查的是复刻样本，不是实时输入；重新录制或正确转换 |
| WAV 很短或背景声音多 | 准备自然连续清晰语音，避免音乐和多人说话 |
| 音色查不到或无法使用 | 核对区域、业务空间、目标模型和完整 ID |
| 修改频率后云端参数错误 | `once/always` 要求 `voice=default`；固定 ID 配 `never` |
| 文件译音成功但会议没声音 | 文件验证不推流会议设备；另外做[虚拟麦克风测试](测试实验室使用.md) |
| 删除录音后列表音色仍在 | 本地音频与云端音色是不同数据，需分别管理 |
