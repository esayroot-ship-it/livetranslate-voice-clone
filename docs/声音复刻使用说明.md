# 声音复刻使用说明

推荐使用正式版“音色管理”页面创建、查询、删除和选择会议音色。

1. 在“接口与翻译”填写百炼配置。
2. 在“音色管理”准备清晰的声音样本，选择本人或已授权的声音。
3. 创建音色后选择该音色供麦克风克隆译音使用。
4. 在测试实验室确认中文到英文等目标语言的克隆译音效果。

CLI 示例的声音样本路径为 `data/voice-clone/recordings/voice_sample.wav`，使用时放入自己的录音或修改本地配置中的路径。公共仓库不包含声音样本；API Key 保存在本地实际配置中。

## 独立 CLI

CLI 源码在 `backend/voice_clone/`；独立配置在 `config/voice-clone/voice_clone.local.yaml`。

从项目根目录运行：

```powershell
.\scripts\manage.ps1 -Action voice prompt
.\scripts\manage.ps1 -Action voice check
.\scripts\manage.ps1 -Action voice list
.\scripts\manage.ps1 -Action voice create
.\scripts\manage.ps1 -Action voice delete YOUR_VOICE_ID
```

创建音色时确认配置中的声音样本路径。删除音色按 CLI 或页面提示确认。正式版 GUI 和独立 CLI 保留各自配置，可以通过对应配置文件明确管理它们。
