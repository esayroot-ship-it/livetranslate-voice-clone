# 测试实验室使用

启动 `start.bat` 后进入“测试实验室”。正式翻译会话与测试会话按页面提示依次运行。

## 推荐顺序

1. 检查配置和设备解析，确认物理麦克风与 VB-CABLE 方向。
2. 执行 VB-CABLE 本地路由测试，确认 CABLE Output 能回录到校准音。
3. 执行字幕效果测试，播放视频或会议测试音，观察原文、译文和悬浮字幕。
4. 执行实时麦克风克隆译音测试，讲话并观察链路延迟和回录状态。
5. 停止测试后试听云端译音和虚拟麦克风回录，确认尾句完整、设备释放。

测试录音保存在 `data/runtime/test_audio/`，可以在测试页面播放或删除。原始的旧测试输出已经移到项目外的回收目录。

## 结果判断

| 云端译音 | 虚拟麦克风回录 | 排查方向 |
|---|---|---|
| 有声音 | 有声音 | 云端生成和虚拟声卡路由可用，继续会议端试听 |
| 有声音 | 无声音 | 检查 CABLE Input/Output 选择、播放状态和音频格式 |
| 无声音 | 无声音 | 检查麦克风电平、语言、音色、云端连接及语音检测 |
| 无声音 | 有其他声音 | 检查 OBS 混音、Windows 监听和其他程序占用 |

## 自动化回归

双击 `run-tests.bat`，或执行：

```powershell
.\scripts\manage.ps1 -Action test
```

测试使用现有本地 Mock 和测试素材，覆盖音频处理、队列、云端事件解析、配置、页面契约、声音复刻及测试引擎。真实云端与会议端可听性按上述页面流程验证。
