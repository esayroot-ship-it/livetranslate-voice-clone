# Web 前端：控制台、字幕配置与音频测试页面

前端使用 HTML、JavaScript 和 CSS，不需要 Node.js、npm 或独立构建。正式版由 Python 后端统一提供页面和 API，默认入口为 `http://127.0.0.1:8788/`。

## 正式版页面

| 源文件 | 页面 | 主要操作 |
|---|---|---|
| `console/index.html` | 总览 | 三种模式、字幕显示来源、麦克风翻译 / 克隆输出、按住说话、启动 / 停止、悬浮窗和链路延迟 |
| `console/config.html` | 接口与翻译 | 百炼配置、语言方向、同语言跳过、VAD、音色策略与热词 |
| `console/audio.html` | 音频设备 | 四类设备选择、媒体 / 麦克风检测、校准、三种预设与传输参数 |
| `console/subtitles.html` | 字幕 | 原文 / 译文、仅对方 / 仅自己 / 双方、字体、透明度与紧凑背景 |
| `console/voices.html` | 音色管理 | 声音样本上传、创建、查询、选择和删除云端音色 |
| `console/test.html` | 测试实验室 | 媒体字幕、实时克隆译音、虚拟路由、延迟、录音试听与删除 |
| `console/status.html` | 后台状态 | 设备、采集、推送、输出与恢复事件 |

`common.js` / `app.css` 提供共享交互与样式，其余脚本对应各页面。真实音频采集由本机 Python 后端完成，不是浏览器直接读取会议进程声音。

## 使用方式与边界

1. 先运行根目录 `start.bat`，再使用浏览器进入控制台。
2. 配置页保存后，根据提示重启翻译会话，使会话参数生效。
3. 页面“停止程序”停止翻译，浏览器仍能继续配置；要关闭整个服务，用根目录 `stop.bat`。
4. 按住说话的自定义快捷键需要总览页面具有焦点，不是全局键盘监听。
5. 不要直接双击 HTML 文件替代后端启动；页面依赖同源 API、状态事件和实际配置。

`virtual-mic/` 是独立测试页面，默认端口 8776；`legacy/` 是原型页面，默认端口 8765。日常使用优先进入正式版测试实验室，避免多套服务同时采集同一个设备。

启动脚本把后端的兼容前端路径映射到本目录；不要复制第二套静态文件到后端。修改页面应在本目录的真实文件中进行。

使用步骤见[根 README](../README.md)和[测试实验室使用](../docs/测试实验室使用.md)。
